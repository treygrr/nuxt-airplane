The module runs [GraphQL Code Generator](https://the-guild.dev/graphql/codegen) at build time and writes `.nuxt/types/nuxt-airplane.d.ts`. You never import from it; the composables pick the types up by document name.

## What is generated

For every operation, the `typescript-operations` plugin emits a result and a variables type named after the operation, exactly as written (`namingConvention: 'keep'`):

```ts
export type GetSitesQuery = { sites: Array<{ id: string, name: string, archived: boolean }> }
export type GetSitesQueryVariables = Exact<{ [key: string]: never }>
export type RenameSiteMutation = { renameSite: { id: string, name: string } }
export type RenameSiteMutationVariables = Exact<{ id: string, name: string }>
```

Those are then mapped onto two global interfaces the composables key off:

```ts
declare global {
  interface NuxtAirplaneQueries {
    GetSites: { result: GetSitesQuery, variables: GetSitesQueryVariables }
  }
  interface NuxtAirplaneMutations {
    RenameSite: { result: RenameSiteMutation, variables: RenameSiteMutationVariables }
  }
}
```

So `useQuery('GetSites')` only accepts names in `NuxtAirplaneQueries`, and `data` is `GetSitesQuery | null`.

## Using the types yourself

Because the maps are global you can reach the generated types from anywhere, for instance to type a helper in a handler file:

```ts
type Sites = NuxtAirplaneQueries['GetSites']['result']['sites']
type Site = Sites[number]
```

## Where the schema comes from

See [`schema`](/getting-started/configuration#schema). In order: an SDL file, a URL, introspection of the endpoint, then the cached copy in `node_modules/.cache/nuxt-airplane`. If none is available the composables are generated untyped (`any`) with a warning, so the app still builds.

## Customising codegen

Pass plugin options through the [`codegen`](/getting-started/configuration#codegen) module option. `ID` is typed as `string` by default; override it or add scalars like so:

```ts [nuxt.config.ts]
airplane: {
  codegen: {
    scalars: {
      ID: { input: 'string', output: 'string' },
      DateTime: 'string'
    }
  }
}
```

## Fragments

Fragments can be defined in any document file. Each operation is sent with exactly the fragments it spreads, resolved recursively, so a shared `fragment SiteFields on Site` works across files.

## Watching

In dev, changes to `.gql` / `.graphql` files and to handler files regenerate the templates and types without a restart.
