```ts
function useAirplaneQuery<N extends QueryName>(
  name: N,
  variables?: MaybeRefOrGetter<QueryInput<N> | undefined>,
  options?: UseAirplaneQueryOptions
): UseAirplaneQueryReturn<QueryResult<N>>
```

## Parameters

| | |
| --- | --- |
| `name` | A query document name from `NuxtAirplaneQueries`. |
| `variables` | Variables for the query, and any [local variables](/guide/stores-and-query-handlers#local-variables) its handler declares: an object, a ref or a getter. Changing the query's own re-runs `read` and refetches; changing a local one only re-runs `read`. |
| `options.fetch` | `false` to never hit the network. Default `true`. |
| `options.enabled` | A boolean, ref or getter. While `false` nothing is read or fetched and `data` is `null`. Default `true`. |

## Returns

```ts
interface UseAirplaneQueryReturn<T> {
  data: Ref<T | null>
  loading: Ref<boolean>
  fetching: Ref<boolean>
  error: Ref<Error | null>
  updatedAt: Ref<number | null>
  refresh: () => Promise<void>
}
```

```ts
/** The query's variables, and any of its handler's local variables. */
type QueryInput<N> = QueryVariables<N> & Partial<QueryLocals<N>>
```

See [Queries](/guide/queries) for how each field behaves.

## Example

```vue
<script setup lang="ts">
const id = ref('site-1')
const { data, loading, refresh } = useAirplaneQuery('GetSite', () => ({ id: id.value }))
</script>
```
