```ts
function defineQueryHandlers(handlers: QueryHandlers): QueryHandlers
function defineQueryHandler<N extends QueryName>(name: N, handler: QueryHandler<N>): QueryHandlers
```

Both give you typed keys, typed `variables` and a typed `data`; the singular form declares one query by name, for one-file-per-query layouts, and returns a map you can spread into the plural form. Default-export the result from a file in the [`handlersDir`](/getting-started/configuration#handlersdir).

## Types

```ts
type QueryHandlers = { [N in QueryName]?: QueryHandler<N> }

interface QueryHandler<N extends QueryName> {
  /** Fetch every following page in the background once a page is fetched. */
  prefetch?: QueryPrefetch<N>
  /** Writes a fresh response into the tables. Runs in a transaction. */
  store?: (ctx: QueryHandlerContext<QueryVariables<N>>, data: QueryResult<N>) => unknown
  /** Builds the result from the tables; what useQuery returns. Runs inside liveQuery. */
  read?: (ctx: QueryHandlerContext<QueryVariables<N>>) =>
    QueryResult<N> | null | undefined | Promise<QueryResult<N> | null | undefined>
}

interface QueryHandlerContext<V> {
  db: AirplaneDexie
  variables: V
}

interface QueryPrefetch<N extends QueryName> {
  /** Variables of the page after `data`, or null at the end. */
  next: (data: QueryResult<N>, variables: QueryVariables<N>) => QueryVariables<N> | null | undefined
  /** Cap per run. Default 1000. */
  maxPages?: number
  /** Skip the run when false. */
  when?: () => boolean
}
```

See [Prefetching every page](/guide/stores-and-query-handlers#prefetching-every-page).

`read` is what makes a query work offline and follow local edits; without it the query is served from the network only. See [Stores and query handlers](/guide/stores-and-query-handlers).

## Example

```ts [app/airplane/queries/get-items.ts]
export default defineQueryHandler('GetItems', {
  store: ({ db }, data) => db.Item.bulkPut(data.items),
  read: async ({ db }) => ({ items: await db.Item.orderBy('name').toArray() }),
})
```

```ts [app/airplane/queries/index.ts]
import getItems from './get-items'
import getSites from './get-sites'

export default defineQueryHandlers({ ...getSites, ...getItems })
```
