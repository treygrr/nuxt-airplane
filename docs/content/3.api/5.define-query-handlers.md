```ts
function defineQueryHandlers(handlers: QueryHandlers): QueryHandlers
```

An identity function that gives you typed keys, typed `variables` and a typed `data`. Default-export its result from a file in the [`handlersDir`](/getting-started/configuration#handlersdir).

## Types

```ts
type QueryHandlers = { [N in QueryName]?: QueryHandler<N> }

interface QueryHandler<N extends QueryName> {
  /** Writes a fresh response into your tables. Runs in a transaction. */
  store?: (ctx: QueryHandlerContext<QueryVariables<N>>, data: QueryResult<N>) => unknown
  /** Builds the result from your tables. Runs inside liveQuery. */
  read?: (ctx: QueryHandlerContext<QueryVariables<N>>) =>
    QueryResult<N> | null | undefined | Promise<QueryResult<N> | null | undefined>
}

interface QueryHandlerContext<V> {
  db: AirplaneDexie
  variables: V
}
```

A query with a `read` handler is no longer cached as a blob; `useQuery` observes `read` instead. See [Stores and query handlers](/guide/stores-and-query-handlers).

## Example

```ts [app/airplane/queries.ts]
export default defineQueryHandlers({
  GetItems: {
    store: ({ db }, data) => db.items.bulkPut(data.items),
    read: async ({ db }) => ({ items: await db.items.toArray() }),
  },
})
```
