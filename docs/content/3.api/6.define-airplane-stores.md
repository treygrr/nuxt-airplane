```ts
function defineAirplaneStores(
  stores: Record<string, string>,
  options?: { version?: number }
): AirplaneStores
```

Default-export its result from a file in the [`handlersDir`](/getting-started/configuration#handlersdir). Several files can declare stores; they are merged and the highest `version` wins.

## Parameters

| | |
| --- | --- |
| `stores` | Table definitions in Dexie's [`stores()` syntax](https://dexie.org/docs/Version/Version.stores()): `'&id, name'`, `'++id, siteId'`, `'[siteId+itemId], siteId'`… |
| `options.version` | Schema version, default `1`. Bump it to change an existing table's primary key. Adding tables or indexes needs no bump. |

## Typing the rows

Augment the global `NuxtAirplaneStores` interface so `db.<table>` is typed in handlers:

```ts [app/airplane/stores.ts]
declare global {
  interface NuxtAirplaneStores {
    sites: { id: string, name: string, archived: boolean }
  }
}

export default defineAirplaneStores({
  sites: '&id, name, archived',
})
```

`db.sites` is then a `Table<{ id: string, name: string, archived: boolean }>`.

## Reserved names

`queries` and `mutations` belong to the module.
