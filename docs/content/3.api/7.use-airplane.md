```ts
function useAirplane(): AirplaneClient | undefined
```

Returns the client the other composables are built on, or `undefined` during SSR. Reach for it when you need something the composables don't expose.

## Members

| | |
| --- | --- |
| `db` | The Dexie instance: `queries`, `mutations` and the tables from `defineAirplaneStores`. |
| `state` | The reactive sync state behind [`useSync()`](/api/use-sync). |
| `documents` | The operation map: `{ [name]: { name, kind, source } }`. |
| `fetchQuery(name, variables)` | Fetch a query and write it to the cache. |
| `enqueue(name, variables)` | What `mutate()` calls. |
| `execute(name, variables)` | What `mutate()` calls with `queue: false`: drains the outbox, sends the mutation now and resolves with the server's data. Rejects while offline. |
| `rollback(id)`, `retry(id)`, `sync()` | Same as `useSync()`. |
| `goOffline()`, `goOnline()` | Same as `useSync()`. |
| `clearCache()` | Empty cached data (query rows and your stores), keep the outbox. |
| `clear()` | Empty every table, including the outbox. |
| `cacheKey` | The effective cache key (`cacheKey` option + documents hash). |
| `ready` | Resolves once the cache-key check has run. |

## Example

Wipe local data on sign-out:

```ts
async function signOut() {
  await useAirplane()?.clear()
  await navigateTo('/login')
}
```
