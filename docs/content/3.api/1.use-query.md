```ts
function useQuery<N extends QueryName>(
  name: N,
  variables?: MaybeRefOrGetter<QueryVariables<N> | undefined>,
  options?: UseQueryOptions
): UseQueryReturn<QueryResult<N>>
```

## Parameters

| | |
| --- | --- |
| `name` | A query document name from `NuxtAirplaneQueries`. |
| `variables` | Variables for the query: an object, a ref or a getter. Changing them re-runs `read` with the new ones and refetches. |
| `options.fetch` | `false` to never hit the network. Default `true`. |

## Returns

```ts
interface UseQueryReturn<T> {
  data: Ref<T | null>
  loading: Ref<boolean>
  fetching: Ref<boolean>
  error: Ref<Error | null>
  updatedAt: Ref<number | null>
  refresh: () => Promise<void>
}
```

See [Queries](/guide/queries) for how each field behaves.

## Example

```vue
<script setup lang="ts">
const id = ref('site-1')
const { data, loading, refresh } = useQuery('GetSite', () => ({ id: id.value }))
</script>
```
