  Returns: The `UseOnlineQueryReturn` interface (`data`, `error`, `fetching`, `updatedAt`, `refresh`). `error` is an `OfflineError`, importable from `#nuxt-airplane`, when the app was offline and nothing was sent.
  Example: A search-suggestions query held back with `enabled` until two characters are typed.
---

```ts
function useOnlineQuery<N extends QueryName>(
  name: N,
  variables?: MaybeRefOrGetter<QueryVariables<N> | undefined>,
  options?: UseOnlineQueryOptions
): UseOnlineQueryReturn<QueryResult<N>>
```

## Parameters

| | |
| --- | --- |
| `name` | A query document name from `NuxtAirplaneQueries`. |
| `variables` | The query's variables: an object, a ref or a getter, compared by value. A change asks again. |
| `options.enabled` | Nothing is sent while `false`. A boolean, ref or getter. Default `true`. |
| `options.refetchOnReconnect` | Ask again on reconnect after a run the network or being offline kept from an answer. Default `true`. |
| `options.server` | Ask while rendering on the server and pass the answer in the page. Default `true`. |

## Returns

```ts
interface UseOnlineQueryReturn<T> {
  data: Ref<T | null>
  error: Ref<Error | null>
  fetching: Ref<boolean>
  updatedAt: Ref<number | null>
  refresh: () => Promise<void>
}
```

`error` is an `OfflineError` (importable from `#nuxt-airplane`) when the app was offline and nothing was sent. See [Online queries](/guide/online-queries) for when it asks and what it keeps.

## Example

```vue
<script setup lang="ts">
const text = ref('')
const { data } = useOnlineQuery('GetSearchSuggestions', () => ({ query: text.value }), {
  enabled: () => text.value.length >= 2,
})
</script>
```
