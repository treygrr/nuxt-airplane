```ts
function defineQueryHandlers<T>(handlers: { [N in keyof T]: QueryHandler<N, T[N]> }): QueryHandlers
function defineQueryHandler<N extends QueryName, L>(name: N, handler: QueryHandler<N, L>): QueryHandlers
```

Both give you typed keys, typed `variables` and a typed `data`; the singular form declares one query by name, for one-file-per-query layouts, and returns a map you can spread into the plural form. Default-export the result from a file in the [`handlers.dir`](/getting-started/configuration#handlersdir). The [`handlers.generate`](/getting-started/configuration#handlersgenerate) option writes a file with empty `store` and `read` hooks for every query that has no handler.

## Types

```ts
interface QueryHandler<N extends QueryName, L = {}> {
  /** Local variables and their defaults: taken by `useAirplaneQuery`, handed to `read` as `local`, never sent or keyed on. */
  local?: L
  /** Fetch every following page in the background once a page is fetched. */
  prefetch?: QueryPrefetch<N>
  /** Writes a fresh response into the tables. Runs in a transaction. `'result'` keeps it whole, per set of variables. */
  store?: 'result' | ((ctx: QueryHandlerContext<QueryVariables<N>>, data: QueryResult<N>) => unknown)
  /** Builds the result from the tables; what useAirplaneQuery returns. Runs inside liveQuery. Optional with `store: 'result'`. */
  read?: (ctx: QueryReadContext<QueryVariables<N>, L>) =>
    QueryResult<N> | null | undefined | Promise<QueryResult<N> | null | undefined>
}

interface QueryHandlerContext<V> {
  db: AirplaneDexie
  /** A query's result kept with `store: 'result'`, to read or change. */
  result: ResultAccessor
  /** What is sent: the variables the query declares. */
  variables: V
}

interface QueryReadContext<V, L> extends QueryHandlerContext<V> {
  /** The handler's local variables, defaults filled in. */
  local: L
}

/** `result(name, variables)`: the variables can be left out when the query needs none. */
type ResultAccessor = <N extends QueryName>(
  name: N,
  ...variables: {} extends QueryVariables<N> ? [variables?: QueryVariables<N>] : [variables: QueryVariables<N>]
) => StoredResult<QueryResult<N>>

interface StoredResult<T> {
  /** The stored result, or `undefined` when none is stored. */
  get: () => Promise<T | undefined>
  /** Stores `data` as the result. */
  set: (data: T) => Promise<void>
  /** Changes the stored result in place; resolves `false` when none is stored. */
  update: (change: (data: T) => void) => Promise<boolean>
  /** Drops the stored result. */
  delete: () => Promise<void>
}

interface QueryPrefetch<N extends QueryName> {
  /** Variables of the page after `data`, or null at the end. */
  next: (data: QueryResult<N>, variables: QueryVariables<N>) => QueryVariables<N> | null | undefined
  /** Cap per run. Default 1000. */
  maxPages?: number
  /** Skip the run when false. */
  when?: () => boolean
}
```

See [Prefetching every page](/guide/stores-and-query-handlers#prefetching-every-page).

`local` declares [local variables](/guide/stores-and-query-handlers#local-variables): filters `read` answers from the tables that the server never sees. The object is their type as well, at `read` and at `useAirplaneQuery`.

`read` is what makes a query work offline and follow local edits; without it the query is served from the network only. See [Stores and query handlers](/guide/stores-and-query-handlers).

`store: 'result'` keeps the whole response in the module's `results` table, one row per set of variables, and reads it back when there is no `read`: for a result with no `id`, such as the signed-in user or settings. A `read` given next to it is used instead. `result(name, variables)` reaches the stored result from any hook; a query that declares required variables needs them there too. See [Results without an id](/guide/stores-and-query-handlers#results-without-an-id).

## Example

```ts [app/airplane/queries/get-items.ts]
export default defineQueryHandler('GetItems', {
  store: ({ db }, data) => db.Item.bulkPut(data.items),
  read: async ({ db }) => ({ items: await db.Item.orderBy('name').toArray() }),
})
```

```ts [app/airplane/queries/get-viewer.ts]
export default defineQueryHandler('GetViewer', { store: 'result' })
```

```ts [app/airplane/queries/index.ts]
import getItems from './get-items'
import getSites from './get-sites'

export default defineQueryHandlers({ ...getSites, ...getItems })
```
