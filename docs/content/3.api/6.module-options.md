```ts
interface ModuleOptions {
  endpoint: string
  schema?: string
  documents: string[]
  handlersDir: string
  dbName: string
  codegen: Record<string, unknown>
}
```

| Option | Default | |
| --- | --- | --- |
| `endpoint` | `'/api/graphql'` | GraphQL endpoint. Relative paths resolve against the app. |
| `schema` | – | SDL file or URL for type generation. Defaults to introspecting `endpoint`. |
| `documents` | `['**/*.gql', '**/*.graphql']` | Operation file globs, relative to `srcDir`. |
| `handlersDir` | `'offline'` | Handler directory, relative to `srcDir`. |
| `dbName` | `'nuxt-offline'` | IndexedDB database name. |
| `codegen` | `{}` | Extra GraphQL Code Generator plugin config. |

Each option is described in [Configuration](/getting-started/configuration).
