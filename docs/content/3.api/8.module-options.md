```ts
interface ModuleOptions {
  endpoint: string
  headers?: Record<string, string>
  persistedQueries: false | 'automatic' | 'manifest'
  documents: string[]
  schema: {
    source?: string
    headers?: Record<string, string>
  }
  handlers: {
    dir: string
    worker: boolean
    generate: boolean
  }
  database: {
    name: string
    cacheKey?: string
  }
  codegen: Record<string, unknown>
}
```

| Option | Default | |
| --- | --- | --- |
| `endpoint` | `'/api/graphql'` | GraphQL endpoint. Relative paths resolve against the app. |
| `headers` | `{}` | Static request headers (public). |
| `persistedQueries` | `false` | Send operations by hash: `'automatic'` (APQ) or `'manifest'`. |
| `documents` | `['**/*.gql', '**/*.graphql']` | Operation file globs, relative to `srcDir`. |
| `schema.source` | – | SDL file or URL for type generation. Defaults to introspecting `endpoint`. |
| `schema.headers` | `{}` | Headers for build-time introspection (server only). |
| `handlers.dir` | `'airplane'` | Handler directory, relative to `srcDir`. |
| `handlers.worker` | `true` | Run the handlers that write to the tables in a web worker. `false` keeps them on the page. |
| `handlers.generate` | `false` | Write a handler file with empty hooks for every query and mutation that has none. |
| `database.name` | `'nuxt-airplane'` | IndexedDB database name. |
| `database.cacheKey` | – | Deploy key; a change wipes the tables (outbox kept). Documents hash is always mixed in. |
| `codegen` | `{}` | Extra GraphQL Code Generator plugin config. |

Each option is described in [Configuration](/getting-started/configuration).
