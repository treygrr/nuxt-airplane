---
title: useMutation
description: Apply a mutation locally and queue it for the server.
navigation:
  icon: i-lucide-pencil
---

```ts
function useMutation<N extends MutationName>(
  name: N
): UseMutationReturn<MutationVariables<N>>
```

## Parameters

| | |
| --- | --- |
| `name` | A mutation document name from `NuxtAirplaneMutations`. |

## Returns

```ts
interface UseMutationReturn<V> {
  mutate: (variables: V) => Promise<MutationRow>
  loading: Ref<boolean>
  error: Ref<Error | null>
}

interface MutationRow {
  id: number
  document: string
  variables: unknown
  status: 'pending' | 'syncing' | 'failed'
  createdAt: number
  error?: string
}
```

`mutate` resolves once the change is applied locally and queued; see [Mutations](/guide/mutations). It rejects only if the `apply` handler throws or the composable is called during SSR.

## Example

```vue
<script setup lang="ts">
const setOnHand = useMutation('UpdateSiteItemOnHand')

function onChange(siteId: string, itemId: string, onHand: number) {
  setOnHand.mutate({ siteId, itemId, onHand })
}
</script>
```
