The module is new and still changing, so an AI assistant is unlikely to know it, or knows an older version. These docs are published as plain text for it to read.

## What is published

| Address | What it is |
| --- | --- |
| [`/llms.txt`](https://treygrr.github.io/nuxt-airplane/llms.txt) | An index: what the module is, every page with a one-line summary and a link to it as Markdown, and a few facts worth knowing first. |
| [`/llms-full.txt`](https://treygrr.github.io/nuxt-airplane/llms-full.txt) | Every page in one file. |
| `/raw/<page>.md` | One page as Markdown, for example [`/raw/guide/mutations.md`](https://treygrr.github.io/nuxt-airplane/raw/guide/mutations.md). |

They are built with the site, so they always say what these pages say.

## In a chat

Paste the address and ask:

```text
Read https://treygrr.github.io/nuxt-airplane/llms-full.txt and help me write
a query handler for a paginated list.
```

The whole file is large. For one topic, give the page instead. **Copy page** at the top of every page copies it as Markdown, and its menu has the page's Markdown link and opens it in ChatGPT or Claude.

## In a coding assistant

Tell it where the docs are, in the file it reads for instructions (`CLAUDE.md`, `AGENTS.md`, `.cursor/rules`, and so on):

```md [AGENTS.md]
This app uses nuxt-airplane (`@treygrr/nuxt-airplane`) for offline GraphQL.
Its API still changes between releases. Before writing code that uses it,
read the index at https://treygrr.github.io/nuxt-airplane/llms.txt and then
the pages that apply.
```

The index is small, so reading it first costs little, and the links in it lead to the page for each topic.

## What an assistant gets wrong

Worth saying up front when you ask for code:

- `useQuery` is now `useAirplaneQuery`. Older examples use the old name.
- A query has nothing to show offline until its [handler](/guide/stores-and-query-handlers) has a `read`, or `store: 'result'`.
- A mutation changes the tables in its handler's `apply`, not in the component.
- The types `QueryResult`, `MutationRow` and [six others](/guide/type-generation#using-the-types-yourself) need no import.
